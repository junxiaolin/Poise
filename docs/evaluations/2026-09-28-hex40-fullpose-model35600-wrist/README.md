## 范围与复现

六个固定腕姿各取一个完整姿态，不覆盖该掌心方向下的全部 yaw。随机组沿用训练的独立 RPY 均匀采样，不是 SO(3) Haar 均匀采样。
Wilson 区间只描述本次有限仿真试验的抽样误差，不代表不同训练 seed 或真机上的不确定性。
这不是 TB 的 frontier 指标；目标采样、单目标统计口径不同。成功后再掉落仍算该目标曾成功；掉落率列只统计成功前掉落。
最初两轮评估因推理模式重置异常或连续切换腕姿引发的仿真器异常中断，其部分结果全部排除；本报告只采用独立进程完整结果。
